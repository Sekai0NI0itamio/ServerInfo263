# Server Info — Modrinth draft

**Title:** Server Info
**Description:** Replies with server name, MOTD, and world seed.
**Command:** `/serverinfo`

## Body

Replies with server name, MOTD, and world seed.

### Usage

`/serverinfo` — run in game chat (OP level 0 / everyone can use it).

### Installation

1. Install Forge 47.4.20 for Minecraft 1.20.1
2. Drop the jar into your `mods` folder
3. Type `/serverinfo` in chat
